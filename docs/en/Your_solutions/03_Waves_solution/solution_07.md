
### **Step-by-Step Solution**

**1. Identify the Given Information**
* Length of the string ($L$): $80 \text{ cm} = 0.8 \text{ m}$
* Number of antinodes ($n$): $4$

**2. State the Relevant Formula**
For a standing wave on a string, each "loop" (which contains one antinode) corresponds to half of a wavelength ($\frac{\lambda}{2}$). 

The total length of the string ($L$) is equal to the number of antinodes ($n$) multiplied by half the wavelength:

$$L = n \cdot \frac{\lambda}{2}$$

To find the wavelength ($\lambda$), we rearrange the formula:

$$\lambda = \frac{2L}{n}$$

**3. Calculate the Wavelength**
Substitute the given values into the rearranged formula (using centimeters for simplicity, though meters work just as well):

$$\lambda = \frac{2 \cdot 80}{4}$$

$$\lambda = \frac{160}{4}$$

$$\lambda = 40 \text{ cm}$$

**Answer:** The wavelength of the standing wave is **40 cm** (or **0.4 meters**).
